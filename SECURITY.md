# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
`swiss-scooters@plhery.com` with:

- the affected route, component, or version;
- reproduction steps or a proof of concept;
- the likely impact;
- any suggested mitigation.

Avoid including real credentials, precise third-party locations, or unrelated
personal data. You should receive an acknowledgement within seven days. A fix
and disclosure timeline will be coordinated according to severity.

## Supported version

Security fixes target the current `main` branch and the production deployment.
Older commits, forks, and third-party deployments are not maintained by this
project.
